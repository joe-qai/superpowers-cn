什么是 Superpowers

项目概述

Superpowers 是一个强大的 AI 技能框架，帮助开发者为 AI 助手创建和管理专业技能。

模块化技能系统

将复杂任务分解为独立的技能模块，便于开发、测试和维护。每个技能都是一个独立的单元，可以单独升级和替换。

多平台支持

一套技能代码，支持 Claude Code、Cursor、Windsurf、Antigravity 等多种 AI 助手平台。

智能技能匹配

基于语义搜索的技能激活系统，AI 能自动选择最合适的技能来处理用户请求。

开发者友好

清晰的 API 设计、完善的文档和丰富的示例代码，让开发者快速上手。

活跃社区

活跃的 GitHub 社区，定期更新和维护，持续添加新功能和新技能。

安全可靠

内置安全检查机制，防止恶意代码执行，保护用户数据和系统安全。

获取源码

下载指南

选择适合你的方式获取 Superpowers 源码

# 使用 HTTPS 克隆
git clone https://github.com/nextlevelbuilder/superpowers.git

# 使用 SSH 克隆（推荐）
git clone git@github.com:nextlevelbuilder/superpowers.git

# 进入项目目录
cd superpowers

直接下载 ZIP 包，适合不需要 Git 的场景：

# 下载地址
https://github.com/nextlevelbuilder/superpowers/archive/refs/heads/main.zip

# 解压后进入目录
unzip superpowers-main.zip
cd superpowers-main

生产环境建议使用稳定版本：

# 列出所有可用版本
git tag

# 切换到指定版本（例如 v2.0.0）
git checkout v2.0.0

# 或直接下载特定版本
https://github.com/nextlevelbuilder/superpowers/archive/refs/tags/v2.0.0.zip
环境配置

安装教程

一步一步完成环境配置和依赖安装

系统要求

  • • Python 3.10+
  • • Node.js 18+ (可选，用于前端开发)
  • • Git (推荐)
  • • 支持的操作系统: macOS, Linux, Windows
# 检查 Python 版本
python3 --version
# 输出应显示 Python 3.10.x 或更高版本

# 检查 Node.js 版本（可选）
node --version
# 输出应显示 v18.x 或更高版本
# 进入项目目录
cd superpowers

# 创建虚拟环境（推荐）
python3 -m venv .venv

# 激活虚拟环境
# macOS/Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

为不同 AI 平台配置技能：

AI 平台 配置命令 配置文件位置
Claude Code python -m superpowers setup claude .claude/skills/
Cursor python -m superpowers setup cursor .cursor/commands/
Windsurf python -m superpowers setup windsurf .windsurf/workflows/
Antigravity python -m superpowers setup antigravity .agent/workflows/
所有平台 python -m superpowers setup all 自动配置所有平台

进阶技巧

经验分享

来自社区的最佳实践和实用技巧

技能命名规范

使用小写字母和连字符命名技能，如 `ui-ux-pro-max`，便于搜索和识别。避免使用空格和特殊字符。

模块化开发

将复杂技能分解为多个小技能，每个技能只负责一个特定任务，提高复用性和可维护性。

测试驱动开发

在编写技能前先编写测试用例，确保技能行为符合预期，便于后续维护和重构。

性能优化

对于频繁调用的技能，考虑缓存机制和异步执行，减少响应时间，提升用户体验。

安全最佳实践

避免在技能中执行未经验证的代码，对用户输入进行严格校验，防止安全漏洞。

社区贡献

积极参与社区讨论，分享你的技能，接受反馈并持续改进，共同推动项目发展。
